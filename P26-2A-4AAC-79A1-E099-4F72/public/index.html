Gerenciador de Fichas e Rolagem de Dados para RPG

Desenvolva um sistema de criação de fichas de personagens e simulação de dados poliédricos (d4, d6, d8, d10, d12, d20). O frontend deve oferecer formulários dinâmicos que calculam modificadores de atributos automaticamente em JavaScript puro, exigindo autenticação OAuth2 do Discord para associar os personagens criados ao jogador. As fichas são salvas como registros estruturados no Cloudflare D1. Além da persistência cadastral, o sistema deve contar com um log de auditoria de rolagens: toda vez que o jogador aciona um teste de atributo, a geração do número pseudoaleatório ocorre na Cloudflare Function, gravando o resultado com data, hora e identificação do autor em uma tabela compartilhada da mesa, evitando fraudes nas jogadas.
